# 环印骑士剑 · Ringed Knight Arsenal

《影之刃零》的实验性独立剑盾武器 Mod 源码。右手环印骑士直剑，左手黑骑士盾；保留原版武器，通过独立物品入口装备。

**版本：0.9.16-local。代码按 PolyForm Noncommercial 1.0.0 公开，限制商业使用，并非 OSI 定义的开源许可证。** 原生伤害与防御代码衍生自 [fjdsjd/pbz-mc](https://github.com/fjdsjd/pbz-mc)，原作者要求的署名见 [NOTICE.txt](NOTICE.txt)。其他依赖保留各自许可证。

## 下载与安装

此仓库公开代码、编辑器辅助代码和安装器，**不提供魂三提取的模型、动作、纹理、音频，不提供游戏文件、解包密钥、个人存档或完整素材包**。GitHub 的「Download ZIP」是源码，不能直接拖进游戏使用。

已有配套完整本地包时：

1. 正常退出游戏，将压缩包完整解压到任意可写目录。
2. 双击 `Install.cmd`。会自动寻找 Steam 游戏目录；找不到时选择包含 `ProjectPBZ` 和 `platform` 的 `PBZ` 文件夹。
3. 启动游戏、读取存档，独立物品「环印骑士剑」会自动加入武器包；在装备菜单里选择它即可。已有该物品时不会重复添加，也不强行换掉当前装备。

自动发放针对**之后加载的每个存档**，并非只改某个固定存档文件。安装器不替换存档，也不自动读取某个存档。若只想指定存档持有，请将 `Config.lua` 中 `auto_grant` 改为 `false`；已经获得的物品不因此删除。

安装器会核对文件和游戏版本，备份原文件与游戏目录内的存档。备份位于游戏目录 `RingedKnightArsenal-Backup`。`Verify.cmd` 仅验证安装包和游戏版本；它不是战斗验收工具。

卸载前先在游戏内换成原版武器并保存，再退出游戏、双击 `Uninstall.cmd`，必要时手动选择 PBZ 目录。卸载恢复被本包覆盖的旧文件；如果覆盖前已有旧版环直，则恢复旧版。不会删除存档，不自动倒回游戏进度。共享 UE4SS 加载器保留，避免影响其他 Mod。安装后被手动修改的文件会保留并提示。升级到不同包前先卸载当前受管理的包。

若提示加载器不同，不要直接覆盖：此原生模块与指定 UE4SS 二进制绑定，需先确认兼容性。原有 UE4SS 设置保留；自定义 ModsFolderPath/ControllingModsTxt 等高级配置可能需要自行接入本包默认 Mods 目录。

- Windows x64；PBZ Steam build **26367565**，`CL-302256_JKS-17280`，UE **5.7.4**。

- 本次发布只做离线发布检查，没有重新启动游戏进行新的实机回归。既有实机反馈不等于全流程兼容保证。

## 操作与当前行为

以下为当前手柄映射；键盘和游戏改键以配置及游戏实际输入为准。

| 输入 | 行为 |
|---|---|
| 轻攻击 | 最多五刀连续轻击，首刀强化 |
| 三角 | 两段重攻击，可按住蓄力；蓄满伤害和杀气削减翻倍 |
| L1 | 举盾、防御；攻击有效判定结束后取消收招并允许接招 |
| L2 | 环直战技轻击完整连段 |
| L1＋圆圈 | 环直战技重击 |
| L1＋三角 | 向脚后方投掷附绳黑火焰壶，落地爆炸 |
| 空中攻击 | 下落攻击 |
| 长按方向键左／键盘 1 | 沿用原版收刀入口；收刀后攻击走拔刀／切刀攻击衔接 |

普通攻击与战技在各自原有判定范围上延长，使用随挥动扫过的判定，形成超出实体剑身的「空气刀」。战技火光的视觉边界不等于判定边界。格挡取消的点火为短暂视觉／声音反馈，不额外加伤。

**保留当前测试平衡：`testing_free_art=true`，战技暂不消耗精纯杀气。** 没有借打包擅自恢复扣费或改变其他战斗数值。发布副本开启自动入包，并移除了本机开发命令执行入口；原开发目录不受修改。

## 目录

- `src/runtime/RingedKnightArsenal/Scripts`：Lua 战斗、装备、交互让权、声音和界面逻辑。
- `src/native`：UE4SS 原生模块、伤害与资源接口、查询和生命周期管理及测试。
- `editor/RingedKnightEditor`：编辑器导入／动画辅助插件源码。
- `src/*.py`：资产生成、动作转换及离线检查。部分需要自行准备的私人输入。
- `installer`：可移植安装器及测试。公开仓库没有 `payload`，不能直接安装。
- [BUILD.md](BUILD.md)：依赖、缺失输入、复现边界。
