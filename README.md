# 环印骑士剑

给《影之刃零》加一套魂三剑盾：环印骑士直剑＋黑骑士盾。独立武器，保留原版装备。

五连轻击、蓄力重击、环直战技、举盾取消、下落攻击，还有往脚后扔的附绳黑火焰壶。

## 操作

- 三角：蓄力重攻击
- L1：举盾，也能取消攻击后摇
- L2：战技轻击连段
- L1＋圆圈：战技重击
- L1＋三角：投壶

## 安装

**这里只放源码，不含模型、动作和音频，下载源码不能直接玩。**

拿到完整包后，退出游戏、解压，双击 `Install.cmd`。进存档后武器自动入包，自己装备即可。卸载用 `Uninstall.cmd`。

当前版本 **0.9.16**，适配 Steam build **26367565**。仍在测试，战技暂不消耗精纯杀气。
